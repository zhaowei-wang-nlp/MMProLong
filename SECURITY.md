# Security reports

For vulnerabilities in MMProLong changes, use this fork's private vulnerability reporting channel if available. Otherwise, contact a corresponding author through the contact information in the [paper](https://arxiv.org/abs/2605.13831). Do not disclose credentials or exploit details in a public issue.

For vulnerabilities independently reproduced in upstream VeOmni, follow [VeOmni's security policy](https://github.com/ByteDance-Seed/VeOmni/security/policy). This fork does not make reporting or response commitments on behalf of the upstream maintainers.
